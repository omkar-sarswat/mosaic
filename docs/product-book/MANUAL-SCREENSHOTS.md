## Preparation

1. Open http://127.0.0.1:8010. The direct links below select the ED Deputy Director demo identity and Operation Mirage case.
2. Use light appearance throughout. If the content area is dark, use the appearance button beside the account menu.
3. Maximise Chrome or Edge; use F11 to hide browser chrome. Start with browser zoom at 100%. Use the highest comfortable screen resolution, preferably 1920 × 1080 or greater.
4. Adjust the graph using its own fit, rearrange, pan and zoom controls. Keep connections, labels, legend and relevant controls readable. Avoid a tiny graph surrounded by empty space.
5. Move the cursor outside the graph and wait for hover effects and layout animation to stop. Capture with Win + Shift + S and save as PNG. Keep a consistent application frame where practical.
6. If a dense network or long financial route cannot fit legibly, capture an overview and an additional close-up. Append `-detail` to the second filename. Do not reduce the entire interface until its labels become unreadable.
